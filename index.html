Challenge B / C / D

Advanced Controls

B

Ambient Control

Atur intensitas ambient menggunakan slider. Gunakan A untuk mengurangi dan Z untuk meningkatkan Ambient Strength.

C

Camera Control

Aktifkan Camera Orbit menggunakan C. Kamera akan mengorbit objek sehingga perubahan posisi viewer dapat diamati melalui specular highlight.

D

Non-Uniform Scale

Tekan N untuk berpindah antara Uniform dan Non-Uniform Scale. Gunakan Scale X/Y/Z untuk melihat pengaruh scaling terhadap Normal Matrix.

—

Shading & Texture

F toggle Flat/Smooth shading, sedangkan T mengaktifkan kontrol texture.

—

Lighting

L menjalankan Light Orbit. Gunakan tombol panah atau W/S untuk mengubah posisi sumber cahaya.

—

Material & UV

Gunakan [ dan ] untuk mengubah UV scale. Gunakan - dan + untuk mengatur shininess.

—

Object Rotation

Tekan P untuk menghentikan atau menjalankan kembali rotasi objek.

—

Reset

Tekan R untuk mengembalikan seluruh parameter playground ke konfigurasi awal.
